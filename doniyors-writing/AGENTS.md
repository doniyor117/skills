# Maintaining this writing reference

Read README.md and SKILL.md before changing the guide. Follow Doniyor’s current instructions over older examples. Preserve the distinction between original writing, explicitly approved drafts, and illustrative suggestions.

Do not turn each correction into a rigid universal rule. Keep private details out of this public repository and its history. Never copy the old private PDF into the repository.

The source files are SKILL.md, references/examples.md, and references/public-context.md. After editing them, update the version/changelog as appropriate and run `python scripts/build_pdf.py`. Inspect the resulting PDF for readable text, working internal/external links, missing characters, and awkward page breaks. Commit the source and PDF together.

Do not claim fresh example text is user-approved unless the conversation explicitly supports that label. Do not send messages or submit applications merely because this guide describes how to draft them.
